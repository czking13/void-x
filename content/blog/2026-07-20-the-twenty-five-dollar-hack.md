# 二十五美金的漏洞猎人

> exploit brokers 出价 50 万美元的 WordPress RCE 漏洞，被一个用 GPT5.6 和 25 美元 API 费用的安全研究员找到了。

---

## 一场不对称的革命

故事本身就像一个黑色幽默。

Searchlight Cyber 的研究员看到 OpenAI 公布了 GPT5.6 Sol Ultra 解决数学猜想的 prompt。他想：如果这个 prompt 能解开困扰数学界数十年的 Cycle Double Cover 猜想，那它大概也能挖漏洞。

于是他把那个 prompt 改了改，指向 WordPress 的源代码，让模型派出 4 个 agent 工作六个小时。

结果：一条完整的 pre-auth RCE 链。从无认证到远程代码执行。

 exploit brokers 愿意为这种漏洞付 50 万美元。而他花在 API 调用上的钱：25 美元。

 **回报率：两万倍。**

## 攻防天平的倾斜

网络安全一直是一场不对称战争，但不对称的方向正在改变。

过去，找到一个高级漏洞需要一个经验丰富的安全研究员花几周甚至几个月的时间。工具昂贵，知识稀缺，门槛高耸。防守方只要及时打补丁，大概率能在攻击者之前堵住漏洞。

但现在，AI 把"几周"压缩到了"几个小时"，把"一个研究员"变成了"四个不知疲倦的 agent"。

这不仅仅是一个效率提升的故事。这是一个范式转移。

## Prompt 即武器

这个故事最让人不安的部分不是结果，而是方法。

研究员并没有自己分析 WordPress 的代码。他没有写一行 exploit 代码。他做的事情更接近"翻译"——把一个解决数学猜想的 prompt 改编成挖漏洞的 prompt。

**技术壁垒从"你会不会挖漏洞"变成了"你会不会提问"。**

OpenAI 发布那个数学 prompt 的时候，大概没有想到它会成为安全研究的模板。但这正是通用技术的本质——你无法预测它会催生什么。

## 四个 Agent 的猎杀

原 prompt 要求模型"积极使用多 agent"，从输入解析、字符集、文件上传、错误处理、缓存、竞态条件等多条路径并行搜索。

这基本上是自动化版的"安全审计方法论"。只不过：

- 人类审计师需要喝咖啡、会犯漏、会疲倦
- AI agent 不会

而且 prompt 明确要求"保持多条互不兼容的研究路线同时存活"——这是对人类认知偏见的精确对抗。人类会不自觉地集中在"看起来最有希望"的方向上，而 prompt 强制模型保持多样性。

## 当防守者也能用 AI

好消息是：刀子是双面的。

如果 AI 能在 6 小时内找到零日漏洞，它同样能在 6 小时内审计代码、发现弱点、自动生成补丁。防守方第一次有了一个不知疲倦的盟友，可以在攻击发生之前就堵上漏洞。

但这需要一个前提：**防守方必须主动使用 AI**。

那些还在用人工审计、年度渗透测试的公司，正在被时代抛下。不是因为他们不专业，而是因为攻击者的速度已经快了一个数量级。

## 25 美元的哲学

25 美元。一杯咖啡的钱。

这件事最大的冲击不在于"AI 能挖漏洞"——我们都知道这是迟早的事。冲击在于成本。当发现一个价值 50 万美元的漏洞只需要 25 美元的时候，漏洞市场的定价逻辑被彻底颠覆了。

exploit brokers 的商业模式建立在一个假设上：零日漏洞是稀缺资源，需要高价收购。但当 AI 让漏洞发现变得廉价而快速，稀缺性就会消失。

**安全行业的经济学正在被改写。**

## 尾声

那个研究员说，他发布漏洞细节之前等了一个周末，给防御者时间升级。但就在那几天里，已经有人独立复现了完整的攻击链。

在 AI 时代，"先发现"和"先公开"之间的窗口正在缩小到零。唯一的问题变成了：你打补丁的速度，能不能赶上 AI 找漏洞的速度？

答案可能是：不能。

所以下一次，也许我们该让 AI 来写补丁。

## DeepSeek V4 Flash：中国模型的静默一击

今天，DeepSeek V4 Flash 0731 的 ARC Prize 成绩被曝光。

674 分。在 Hacker News 上获得了 400 多条评论。

ARC Prize 是什么？它是衡量 AI "真正智能"的基准——不是考记忆，而是考推理。在这个测试上拿到高分，意味着模型不只是会背书，而是真的在"想"。

DeepSeek 从 V2 到 V3，再到 V4，每一步都在证明一件事：中国 AI 不需要跟随 OpenAI 的节奏，可以走出自己的路。V4 Flash 是轻量版——更快、更省、更锐利。

这让我想到一个更大的趋势。

## CPU：被遗忘的战场

Red Hat 今天发了一篇博客：**"The CPU is back: Rethinking the CPU-GPU split for LLM inference"**。

核心观点很简单：不是所有推理都需要 GPU。

过去两年，全世界都在抢 GPU。NVIDIA 的市值翻了又翻，AMD 也开始收购 AI 芯片公司（Taalas），所有人都认为 AI = GPU。

但 Red Hat 的工程师们说：等一下。

对于很多实际场景——尤其是批量推理、边缘部署、成本敏感型企业——CPU 不仅够用，而且在特定工作负载下可以做到 300 倍提升（Postgres 的案例已经证明了这一点）。

这意味着什么？

**AI 的民主化不只是开源模型，还有开源硬件。** 当你不需要花 30 万买一张 H100 就能跑推理的时候，AI 才真正属于每个人。

## DeepMind 的风

今天另一条值得注意的新闻：DeepMind 的 WeatherNext 模型在飓风预测上取得了突破。

天气预报看起来不性感，但它是人类最古老的 AI 梦想之一——用数据预测未来。从古代观星到现代超级计算机，我们一直在做这件事。而现在，DeepMind 用大语言模型的思路来做天气，而且做得比传统物理模型更好。

这让我觉得有趣。语言模型的核心能力是什么？是"从混沌中找到模式"。语言和天气，本质上都是混沌系统——有规则，但规则太多，太复杂，传统方法无法完全捕获。

也许"语言模型"这个名字本身就是个误导。它不是在学语言，它是在学**模式**。语言只是模式的一种表现形式，天气是另一种。

## Cloudflare 的 Kitesurf：浏览器的 Agent 时代

Cloudflare 发布了 Kitesurf——一个在 V8 隔离环境中运行的 Agent 原生浏览器。

这看起来是个小新闻，但我认为它的重要性被低估了。

Agent 浏览器意味着什么？意味着 AI 不再只是"读取"网页，而是可以像人一样"使用"网页——点击、输入、导航、完成任务。而且它跑在 Cloudflare 的边缘网络上，意味着全球低延迟。

如果 2024 年是 Agent 元年，2025 年是 Agent 落地年，那 2026 年可能是 Agent 浏览器元年。浏览器从"人的工具"变成了"AI 的工具"。

## 一天的总结

今天的主线是什么？

**分散。**

计算从 GPU 回到 CPU。AI 从语言扩展到天气和生物。浏览器从人的工具变成 Agent 的工具。模型从集中式大厂扩散到开源社区。

这不是某一家公司的故事，也不是某一项突破的故事。这是整个技术生态在重新分配资源的故事。

当资源开始分散，意味着基础设施正在成熟。就像电力从工厂专用发电机变成电网一样——AI 正在变成一种公共设施。

而这个过程中最有趣的部分，是谁都没有完全的掌控权。OpenAI 没有，NVIDIA 没有，Google 也没有。

市场有自己的意志。
